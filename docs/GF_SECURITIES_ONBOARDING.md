# 广发证券接入清单

> **未来接入询问清单**：本文用于向券商核实 QMT/API 条件，不表示仓库已经接入广发、QMT 或 XtQuant，也不授权真实交易。

广发官网确认提供 QMT 量化交易系统，但公开页面没有承诺个人存量账户的开通门槛、费用、外部 XtQuant、模拟盘和 L2 API 权限。这些项目必须由 95575 或开户营业部逐项确认。

## 确认账户类型

1. 登录官方“广发易淘金”。在“我的 → 业务办理”查看账户资料、业务权限和普通账户对账单。
2. 查看是否存在独立的信用资金账户或股票期权账户。只有普通交易入口通常意味着普通现金账户，但最终仍以客服确认为准。
3. 拨打 95575，询问名下各资金账户类型、开户营业部，以及已开通的沪深 A 股、创业板、科创板、北交所、信用和期权权限。

不要向项目或聊天提供客户号、股东号、身份证、密码、验证码或 Token。

## 可直接发送给客服/客户经理

> 本人是贵司个人客户，仅用于本人账户、不代客，拟用 Python 开发程序化交易系统。请逐项书面确认：
>
> 1. 我的账户是普通现金、信用还是其他类型，已开通哪些市场和产品权限？
> 2. 个人存量客户能否申请 QMT/MiniQMT？是否包含外部 `xtquant` 原生 Python 行情和交易 API，而不只是 QMT 内置模型？
> 3. 资金门槛如何计算、需要维持多久，软件、接口和行情有哪些费用？
> 4. 是否提供与实盘同 API 的仿真账号或测试柜台？
> 5. 标准行情是否包含沪深全市场 L1 实时和历史 Tick、1分钟及日线？历史范围和订阅上限是什么？
> 6. Level-2 能否通过 Python API 使用，而不只是终端展示？是否包含 `l2quote`、`l2order`、`l2transaction` 和 `l2orderqueue`，各自费用、标的数量和历史范围是什么？
> 7. 易淘金购买的 Level-2 是否会自动授权到 QMT/XtQuant API？
> 8. 程序化交易报告在哪里提交，需要哪些材料、审核多久、允许申报/撤单速率是多少？
> 9. 支持哪些市价、IOC/FOK 和算法委托？
> 10. 请提供 Windows 官方安装包、XtQuant SDK版本、API文档和升级政策。

同时询问股票、ETF 和可转债的实际佣金及最低佣金。

## 注册顺序

1. 优先申请广发 QMT/MiniQMT、外部 XtQuant、L1 行情和模拟环境。
2. 并行注册掘金量化，先使用免费线上仿真，并询问广发券商版是否可绑定现有账户。
3. 注册 Tushare 免费账号；长线数据需要时再购买 200 元/年的 2000 积分档。
4. 申请 RQData 免费试用，比较历史分钟、Tick 和 point-in-time 财务质量。
5. 暂不申请 PTrade、XTP 或 TORA，也不从非官方低佣开户链接购买接口。

## 只需脱敏回传

- 开户营业部所在城市或名称；
- 普通/信用/期权账户类型；
- 资产大致档位：10万以下、10–50万、50–100万或100万以上；
- 客服对上述问题的文字答复；
- 官方 QMT/SDK 版本、下载路径、费用表和模拟资格。
